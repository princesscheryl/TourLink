# TourLink Image Placement Guide

## Where to Place Images

All images should be placed in the corresponding folders within `/assets/images/`

---

Download and save these official logos:

1. **Ghana Tourism Authority** → Save as: `gta-logo.png`

   - Website: https://www.touringghana.com/
   - File format: PNG with transparent background preferred

2. **Ministry of Tourism** → Save as: `ministry-tourism-logo.png`
   - Search: "Ghana Ministry of Tourism Arts and Culture logo"
   - File format: PNG with transparent background preferred

3. **GHATOF** → Save as: `ghatof-logo.png`

   - Search: "GHATOF Ghana Tourism Federation logo"

**Image specs:**
- Format: PNG (transparent background)
- Max height: 200px
- Max width: 400px

## Image Optimization Tips

Before uploading:
1. **Resize images** - Don't upload huge files
   - Partner logos: Max 200px height
   - Provider photos: 800x600px
   - Experience photos: 1200x800px

2. **Compress images** using:
   - TinyPNG: https://tinypng.com/
   - Squoosh: https://squoosh.app/

3. **File naming** - Use lowercase, hyphens (not spaces)
   - ✅ Good: `kente-weaving.jpg`
   - ❌ Bad: `Kente Weaving Photo.JPG`

---

## Fallback Behavior

If images are missing, the site will show icon placeholders (already configured). Add images gradually as you find them.
