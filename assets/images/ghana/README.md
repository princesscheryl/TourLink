# Ghana Images Directory

This directory contains static images of Ghana for the "Why Visit Ghana" section on the Community Tourism page.

**Location:** `/assets/images/ghana/`

## Required Images

Place the following images in this directory:

### Historical & Cultural
1. **independence-square.jpg** - Independence Square in Accra (Black Star Monument)
2. **kente-weaving.jpg** - Traditional Kente cloth weaving in Bonwire
3. **adinkra-symbols.jpg** - Adinkra symbols on cloth or pottery
4. **drumming-dancing.jpg** - Traditional Ghanaian drumming and dancing

### Tourist Destinations
5. **cape-coast-castle.jpg** - Cape Coast Castle (UNESCO World Heritage Site)
6. **kakum-canopy-walkway.jpg** - Kakum National Park canopy walkway
7. **mole-national-park.jpg** - Elephants at Mole National Park
8. **labadi-beach.jpg** - Labadi Beach in Accra

## Image Specifications

- **Format:** JPG or PNG
- **Recommended size:** 1200x800px minimum
- **Aspect ratio:** 3:2 or 16:9
- **File size:** Under 500KB (optimized for web)
- **Quality:** High resolution, well-lit, professional looking

## Image Sources

Use royalty-free images from:
- Ghana Tourism Authority official site
- Unsplash (search "Ghana")
- Pexels (search "Ghana")
- Your own photography

**Important:** Ensure you have rights to use all images. Credit photographers where required.

## Fallback Behavior

If an image is not found, the code will display a colored gradient background as a fallback.
